Документация API — бесплатный тренажёр

Живой REST API для практики тестирования. Работает на api.eddytester.com.

Как пользоваться

  1. Получи ключ на странице тренажёра — он действует 24 часа
  2. В каждом запросе передавай заголовок X-Fix-Bug: твой_ключ
  3. Без ключа или с неверным ключом сервер отвечает 401

Методы

POST /free/api/users — создать пользователя

Создаёт нового пользователя. Тело запроса — JSON:

ПолеТипОписание
namestringИмя пользователя
agenumberВозраст

Пример запроса:

curl -X POST https://api.eddytester.com/free/api/users \
  -H "X-Fix-Bug: твой_ключ" \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice","age":25}'

Успешный ответ — 201 с созданным пользователем в JSON.

GET /free/api/users — список пользователей

Возвращает список созданных пользователей. Поддерживает параметр limit — сколько записей вернуть:

curl "https://api.eddytester.com/free/api/users?limit=5" \
  -H "X-Fix-Bug: твой_ключ"

Успешный ответ — 200 с массивом пользователей в JSON.

GET /free/api/users/:id — пользователь по id

Возвращает одного пользователя по его идентификатору:

curl https://api.eddytester.com/free/api/users/2 \
  -H "X-Fix-Bug: твой_ключ"

Успешный ответ — 200 с пользователем в JSON.

Коды ответов

КодКогда
200 / 201Запрос выполнен успешно
400Запрос некорректный (неверные данные)
401Ключ отсутствует или неверный
500Ошибка сервера
Важно: сервис учебный — в его поведении есть несоответствия этой документации. Твоя задача — найти их. Сверяй ответы сервера с тем, что написано здесь.
